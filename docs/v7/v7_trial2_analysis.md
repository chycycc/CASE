---

## 1. 实验定位与架构演进目标

在 V7 Trial 1 中，高阶解缠残差投影头（ERP）成功打破了特征秩坍塌，验证集准确率破 45.06% 创历史新高，生成多样性明显反弹；但其测试集准确率（40.46%）与验证集存在 4.6pp 鸿沟，且隐空间流形仍处于微负状态。这确凿印证了“全局静态 64 原型无法适应微观对话语境变异”的科学痛点。

**V7 Trial 2 (Phase 1b) 作为复合增强实验，核心自变量如下**：
- **基石保留**：继承 Trial 1 的全部配置（ERP 768 维高维解缠、PCAM 跨注意力、残差分类头、64 原型、余弦退火、ACF-BCF 动态冻结）；
- **唯一核心改动**：激活 **上下文条件超网络原型 (Context-Conditioned Hyper-Prototypes, CCHP)**：
  - 动态语境位移幅度：$\alpha_{\text{dyn}} = 0.1$；
  - 动态位移 L2 正则约束惩罚权重：$\mathcal{L}_{\text{reg}} = 0.01$，严格防止参数空间坍塌为平凡解；
  - 超网络以全局编码向量 $\mathbf{h}_{\text{ctx}}$ 为条件输入，自适应生成 64 原型的微观漂移场 $\Delta \mathbf{P}$。

## 4. 核心学术突破与理论启示

### 突破 1：确定性束搜索（Beam Search）多样性创全项目历史纪录
- 长期以来，基于先验引导的生成模型最遭审稿人诟病的便是“束搜索下的模式坍塌（Mode Collapse）”——在 $k=5$ 的确定性解码中，模型往往退化为生成毫无营养的安全套话（如 `"i am sorry to hear that"`），在 V6 Trial 4 中 Beam 唯一句率一度暴跌至 17.55%；
- **实测数据表明**：在引入 CCHP 动态语境位移场后，**Beam 唯一句率暴涨至 31.65%**（较 V6 强多样性版本提升 **+14.10pp**，创全项目历史最高纪录），**Beam Dist-2 达到 3.77%**（超越原版 CASE 3.40% 与 V6 2.63%）；
- **理论因果归因**：全局静态原型是导致安全套话的“元凶”——当同一个情绪标签下的所有样本都被拉扯向同一个固定坐标时，Decoder 会被强烈诱导生成高频平庸词。CCHP 的语境超网络为每个对话样本动态注入了独一无二的微观位移偏置 $\Delta \mathbf{P}(\mathbf{h}_{\text{ctx}})$，使得 Decoder 在检索情感原型时具备了上下文特异性，从而彻底激活了束搜索路径的多样性分支！

### 突破 2：情感判别性能与交叉熵损失双双回升
- 相比于 Trial 1，**测试集 Emo Acc 从 40.46% 回升至 40.89%**；
- **测试集 Emo Loss 从 2.2299 压低至 2.1792（净降 0.0507）**；
- 隐空间 DBI 指数从 4.0731 优化至 4.0390，证明 CCHP 动态调制与 L2 正则协同生效，不仅盘活了生成多样性，而且增强了判别边界的鲁棒性。

## 5. 局限性与下一步决策 (Road to Phase 2)

尽管 Beam Dist-2 已经达到 3.77% 历史最佳，但距离顶会顶级标准（如 6.0%+）仍有提升空间。
当前模型的生成损失仍完全基于标准交叉熵 $\mathcal{L}_{\text{NLL}}$，这在训练端依然会对常见高频词汇给予正向似然奖励。

**Phase 2: V7 Trial 3 攻坚目标**：
- 引入 **序列级无似然训练损失 (Sequence-level Unlikelihood Loss, $\mathcal{L}_{\text{UL}}$)**；
- 惩罚候选集中的安全废话词元（Negative Candidates），强迫 Decoder 探索信息量更丰富的词汇分布；
- **冲刺目标**：在 Beam Search 协议下，推动 Beam Dist-2 突破 **6.0%+**！
