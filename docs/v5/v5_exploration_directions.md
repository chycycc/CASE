# CASE-EPCL V5 可探索方向与优先级规划

> **起点基线**：V4 Trial 8（Dist-2: 5.01%, PPL: 33.82, Emo Acc: 40.34%, 唯一率: 56.0%）
> **V5 主线目标**：在不引入新架构模块的前提下，通过训练工程精调与评测补全，稳健提升当前数值并补齐论文所需数据。

---

## 一、V4 实验中浮现的全部可探索方向总览

### 1. 训练工程层（稳健提升数值）⭐ V5 主线

| 方向 | 描述 | 预期收益 | 风险 |
|:---|:---|:---|:---|
| **余弦退火替代线性衰减** | 将 28k 步后的 LR 衰减策略从线性改为余弦退火（Cosine Annealing），后半程收敛曲线更平滑 | PPL 可能进一步下降 0.3~0.8 | 低：纯调度策略变更，无架构改动 |
| **α_mim 精细网格搜索** | 当前 α=0.1 是从 0.5 一步跳下来的粗调值，0.05 / 0.08 / 0.12 / 0.15 的效果未知 | 可能找到更优的多样性-准确率平衡点 | 低：单变量控制实验 |
| **div_loss 系数微调** | 当前 2.0x 是 1.5x（坍缩）与 3.0x（过拟合）的折中，1.8x / 2.2x / 2.5x 可进一步探索 | Dist-2 在 5.01% 基础上可能有小幅提升空间 | 中：需警惕重蹈 Trial 6 过拟合 |
| **分类头自适应冻结** | 28k 步冻结是经验值；改为基于验证集 Emo Acc 连续 N 步不再上升时自动冻结 | 更稳健的跨数据集泛化 | 低：逻辑简单，无架构改动 |
| **Warmup 步数调整** | 当前预训练 4 epoch + warmup 24000，可尝试缩短或延长预训练阶段 | 可能影响特征空间初始质量 | 中：预训练与主训练的交接点敏感 |

### 2. 评测与泛化层（论文数据补全）

| 方向 | 描述 | 论文价值 |
|:---|:---|:---|
| **Beam Search Dist 指标** | 当前所有多样性数据均基于 Top-k/Nucleus Sampling，Beam Search (beam=5) 下的 Dist 数据是审稿人常问项 | 高：补全 Table 1 |
| **ESConv 数据集迁移** | 将 V4 MoP-DR 架构一键迁移至 ESConv（情绪支持对话），验证跨数据集通用性 | 高：证明方法泛化性 |
| **人工评测 + Case Study** | 从 `results.txt` 抽样做人工标注，制作 Fluency / Empathy / Relevance 三维评测表 | 高：顶会必备 |
| **更多 Baseline 横向对比** | 与 MISC、KEMP、MultiTRS 等同期共情模型对比 | 高：丰富实验章节 |

### 3. 架构创新层（下一代研究方向）

| 方向 | 描述 | 创新度 | 工作量 |
|:---|:---|:---:|:---:|
| **GA-PCL 图内源性对比学习** | 将对比学习从聚合后的 `fine_emotion` 下放至 `cs_graph_encoder` / `concept_graph_encoder` 的 Transformer 节点输出层，对图内节点做原型对比 | ⭐⭐⭐⭐⭐ | 大 |
| **U-InfoNCE 统一变分下界** | 推导统一损失函数，在同一对比空间内同时优化局部 MIM 与全局 EPCL | ⭐⭐⭐⭐⭐ | 大 |
| **MoP-DR 路由升级** | Top-K 稀疏激活（类 Switch Transformer）或注意力池化路由替代当前的全连接标量路由 | ⭐⭐⭐ | 中 |

### 4. 工程债务清理

| 方向 | 描述 | 紧迫度 |
|:---|:---|:---:|
| **NoamOpt/Scaler LR Bug 根治** | 当前 LR 恒定在 3.125e-4 是 `scaler.step()` 绕过 NoamOpt 的遗留 Bug，V4 用线性衰减做了 workaround，根因未修 | 中 |
| **`react_ctx_encoder` OOM 热点** | `model.py` 中 4D `.repeat()` 拼接操作在 4GB 显存下是最可能触发 OOM 的单一操作，扩大 batch_size 必须先解决 | 扩容时高 |
