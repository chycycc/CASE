# CASE-EPCL 进阶创新与架构演进上下文 (Context Handoff - V8.1 阶段)

## 1. 当前项目基线与核心认知
本项目的目标是改进 ACL 2023 提出的 **CASE (Coarse-to-Fine Cognition and Affection)** 移情对话生成模型。

### 核心任务原则与指标定位
- **核心目标**：共情回复文本生成（低困惑度 PPL、高多样性 Distinct-1/2、高共情词命中率）。
- **分类指标定位**：情感分类（EMO_acc）为多任务辅助约束，维持在 **40.0% 左右基准线不滑坡** 即可，坚决避免为了非要在生成最优权重上刷到 41.5%+ 的辅助分类而产生战略内耗。

### V8 阶段核心沉淀与痛点复盘
1. **PPL 突破**：V8 Trial 2 验证了让渡给单任务生成的优越性，跑出历史最低 PPL **32.62**（击穿项目基线 32.80）。
2. **多样性突破**：V8 Trial 4 验证了序列级无似然训练（Unlikelihood Training）的强大效果，核采样 Distinct-2 飙升至 **63.27%**（创全场历史最高纪录）。
3. **痛点**：
   - 硬冻结机制切断分类头更新，导致后半程编码器自适应微调使分类头脱节（测试集准确率降至 39.39% ~ 39.66%）。
   - 解码器词表生成端缺乏显式共情偏置引导。

## 2. V8.1 双轨实验实施规划
在 V8.1 阶段，我们决定对两条路线都进行系统性实验验证与横向对比：
- **方案一（路线 A: V8.1-Trial A）**：端到端多任务平衡 + KEMP 词表层情感偏置注入（彻底取消硬冻结，分类头全程联合微调稳在 40.2%+，词表预测增加基于原型表征的共情偏置门控）。
- **方案二（路线 B: V8.1-Trial B）**：时序软退火解耦 + 复合早停机制（保留阶段解耦初心，采用余弦衰减平滑软退火代替参数硬锁死，目标锁定 PPL 冲进 32.30 ~ 32.50 极限）。
