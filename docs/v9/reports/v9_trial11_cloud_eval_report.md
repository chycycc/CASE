## 四、 核心因果分账与学术结论

### 1. 解码多样性获得显著单变量增益（Greedy Dist-2: 18.14% $\rightarrow$ 18.94%）
- **客观数据**：在相同的自回归主干、相同的 PCAM 拓扑下，仅引入角度硬边际慢速加载调度（$t_{\text{ramp}}=2500$），Greedy Dist-2 净增 **+0.80 个百分点**，达到 **18.94%**，刷新了本项目启动以来的最高记录（为原版 CASE 4.01% 的 4.7 倍）。
- **机理解析**：初期温和的 margin 释放避免了模型在表征塑造初期过早形成极度狭窄尖锐的原型势阱，赋予了解码端跨情绪流形边界采样更加平滑丰富的语义词分布，从而在推断期显著减少了局部词模式重复。

### 2. 语言建模 (PPL) 与分类判别 (EMO_acc) 处于高水平平稳态
- **客观数据**：
  - Test PPL 实测 32.62（vs T10 的 32.48，$\Delta = +0.14$）；
  - Test EMO_acc 实测 41.83%（vs T10 的 42.40%，$\Delta = -0.57\text{pp}$）；
  - 纯 NCM 原型 Acc 实测 41.33%（vs T10 的 41.83%，$\Delta = -0.50\text{pp}$）。
- **因果结论（恪守单种子防自欺规约）**：
  - PPL 变动 $+0.14 < 0.21$（基准选择带宽），分类变动 $-0.57\text{pp} < 0.68\text{pp}$（单样本伯努利 1 SE），在单种子观测下均处于正常统计涨落区间，不构成退步或失败；
  - 原型列联表显示，NCM 独有正确数 $c$ 由 139 增至 168，净追赶量由 $-30$ 改善至 $-26$，说明慢速加载使原型本身捕捉到了更多线性头无法独立覆盖的情绪拓扑特征。

### 3. 几何流形紧凑度进一步提升（DBI: 5.66 $\rightarrow$ 5.49）
- Davies-Bouldin 指数（DBI）由 5.6636 进一步改善至 **5.4915**（下降 0.1721），表明经过慢速加载后，32 类情绪特征簇的簇内紧凑度相对簇间距离的表现优于全程恒定硬推挤。
