本报告经独立交叉审计两轮复核，针对事实、代码与数学统计完成以下闭环核正：

   - **T10 (32.48) 与 T11 (32.62) 均在 `batch_size=1` 下运行，属于同口径合法对照**，历史文档无需改动；
3. **实质变更收敛为两项（F2）**：在云端 `accum_steps=1` 下，D9 损失归一化为数学恒等变换（$x/1 \equiv x$），故 T10 到 T11 的实质变更收敛为 **D8（全局梯度裁剪激活）+ ramp 慢速加载调度**两项（若未来在小显存下启用 `accum_steps>1`，D9 则转为实质生效）；
4. **表 A PPL 双轨并列呈现（F7 / Y1）**：如实呈现 Test PPL 达到绝对硬红线（$32.62 \le 32.88$ 🟢 通过），但未达成相对 T10 的方向性要求（$32.62 > 32.48$ 🟡），落入单种子不可判定带宽；
5. **DPFC 跨模式对照修正与系统性落空加固（F3 / Y4）**：删除 T10(logit域) 与 T11(prob域) 最优值直接相减，标为“不可比”，改为分别说明两轮后验融合相对各自基线均无显著增益（$-0.32\text{pp}$ vs $+0.02\text{pp}, p=1.0$），且两轮 Dev 寻优收益在 Test 上全部反转落空，定谳关闭该离线融合路线；

## 三、 训练过程与时序动力学审计

### 1. 真实停止原因审查（事实纠正）
- **事实审查**：代码中不存在自参照过程熔断机制（`grep -rn "熔断" src/` 仅命中方案注释与文档）。
- **实际停止条件**：**模型跑满预设的 `max_step=10000` 步正常结束训练**；
- **早停状态**：Step 7499 达到最优（Score=48.9825, Valid PPL=37.6652），随后的 Step 7999~9999 历次评估均未超过此得分，`patience` 计数逐步累积至 **5/6**，尚未触及 6 次早停上限，最终随步数打满而退出。

### 2. 三点真实时序图对齐核验
- **Step 0 ~ 2500（慢速加载期）**：`effective_margin` 由 0 严格线性爬升至 0.30（日志确证：Step 0 为 0.0000，Step 1000 为 0.1200，Step 2000 为 0.2400，Step 3000 为 0.3000 满载）；

- **Step 3000 ~ 9000（余弦学习率衰减期）**：LR 从峰值 5.76e-4 持续余弦退火；
- **时序平稳性**：各调度梯次衔接平稳，Valid PPL 从 Step 2999 的 42.79 持续平缓降至 Step 7499 的 37.66，未发生梯度发散。

## 四、 核心因果分账与学术结论（去防御化与客观化）

1. **联合变更下的综合效应**：
   - 本次运行包含 D8 梯度裁剪真实激活（日志打印 21 次 `[Gradient Norm]`）与 ramp 慢速加载两项实质变更（D9 在当前配置下为恒等变换），**因此观察到的指标变动属于工程补丁与调度优化的联合净效应**；
2. **解码多样性（Greedy Dist-2: 18.14% $\rightarrow$ 18.94%）**：
   - 数值测得 18.94%，高于 T10 的 18.14%（+0.80pp），但 500 样本下独立两比例检验 $z=0.33$ 未达统计显著（受限于 `results.txt` 缺乏逐样本多样性标记，无法进行更强力的配对检验，此检验为保守近似），应定性为“具备正向改善倾向，但需更大样本量或多种子验证”；
3. **语言建模与分类判别落入等价带宽**：
   - Test PPL 实测 32.62（守住 32.88 绝对红线，但高于 T10 的 32.48 约 0.14 点，未达“低于 T10”的方向性预期）；
   - Test EMO_acc 实测 41.83%（落后 T10 约 0.57pp，NCM 落后 0.50pp，未破 41.83% 硬门槛）；
   - 两项变动均落入单种子不可判定带宽（PPL 0.21 与 Acc 0.68pp），表明在当前架构与单卡批大小下，模型处于同质能力平台；
4. **DPFC 离线后验融合路线正式关闭（Dev 乐观与泛化背离的系统性实证）**：
   - T10 中 Dev 寻优最高为 DPFC 44.77% > Linear 44.31%，但测试集反转为 DPFC 42.07% < Linear 42.40%（负增益）；
   - T11 中 Dev 寻优最高为 DPFC 43.81% > Linear 43.77%，但测试集缩窄为 DPFC 41.85% ≈ Linear 41.83%（$\Delta = +0.02\text{pp}, p=1.0$ 零增益）；
   - 连续两轮实测证实：在表征固化的后处理阶段，Dev 集寻优存在系统性乐观偏差，加权融合收益无法泛化至测试集，正式定谳关闭离线后验融合路线。
