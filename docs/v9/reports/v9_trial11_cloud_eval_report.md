- **时序平稳性**：各调度梯次衔接平稳，Valid PPL 从 Step 2999 的 42.79 持续平缓降至 Step 7499 的 37.66，未发生梯度发散。

## 四、 核心因果分账与学术结论（去防御化与客观化）

1. **联合变更下的综合效应**：
   - 本次运行包含 D8 梯度裁剪真实激活（日志打印 21 次 `[Gradient Norm]`）、D9 损失归一化以及 ramp 慢速加载三项变更，**因此观察到的微幅变动属于工程补丁与调度优化的联合净效应**；
2. **解码多样性（Greedy Dist-2: 18.14% $\rightarrow$ 18.94%）**：
   - 数值测得 18.94%，高于 T10 的 18.14%（+0.80pp），但 500 样本下 $z=0.81$ 未达统计显著，应定性为“具备正向改善倾向，但需更大样本量或多种子验证”；
3. **语言建模与分类判别落入等价带宽**：
   - Test PPL 实测 32.62（高于 T10 的 32.48 约 0.14 点，未达“低于 T10”的方向性预期）；
   - Test EMO_acc 实测 41.83%（落后 T10 约 0.57pp，NCM 落后 0.50pp，未破 41.83% 硬门槛）；
   - 两项变动均落入单种子不可判定带宽（PPL 0.21 与 Acc 0.68pp），表明在当前架构与批大小下，模型处于同一能力平台；
4. **DPFC 离线后验融合路线正式关闭**：
   - DPFC 融合准确率在 T11 仍为 41.85%（$p=1.0$），连同 T10 的负增益结果（42.07% vs 42.40%），从经验上证实：在特征已固化的检查点上简单做后验加权无法突破单模型表现。
