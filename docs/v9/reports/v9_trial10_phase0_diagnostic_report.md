## 一、PCAM 六模式纯前向诊断

### 1. 测量矩阵

| 模式 | 结构 | Test PPL | ΔPPL | Test EMO Acc |
| :---: | :--- | :---: | :---: | :---: |
| A | $\mathrm{LN}(h_t + \Delta)$ | 32.7774 | 0.0000 | 41.20% |
| B | $\mathrm{LN}(h_t)$ | 38.0775 | +5.3001 | 41.20% |
| C | $h_t$ | 82.4456 | +49.6682 | 41.20% |
| D | $h_t + \Delta$ | 82.6657 | +49.8883 | 41.20% |
| E | $h_t + \tanh(\gamma)(\mathrm{gate} \odot \mathrm{LN}(h_{proto}))$（proxy） | 97.1775 | +64.4001 | 41.20% |
| C′ | $\mathrm{LN}_{out}(h_t + \mathrm{bypass})$（proxy，未训练 LN_out） | 103.5328 | +70.7554 | 41.20% |

EMO Acc 在六模式下恒为 41.20%，与分类头只依赖编码器分支（`fine_emotion`）的解耦事实一致。

### 2. 尺度实测（模式 S）

| 量 | 实测值 |
| :--- | :---: |
| $\|\Delta h\| / \|h_t\|$ | 9.72% |
| $\mathrm{std}(h_t)$ | 1.0128 |
| $\mathrm{std}(\mathrm{LN})$ 输出 | 1.6196 |
| 门控 gate 均值 | 0.3892 |
| `pcam.layer_norm.weight` | 均值 1.6096，标准差 0.1165，范围 [1.3354, 1.9126] |

LN 输出方差（1.6196）与仿射权重均值（1.6096）几乎相等，说明该方差由**仿射重标定**而非 Δ 贡献。

### 3. 因果纠偏（本报告的核心结论）

**纠偏 1：Δ 的训练期因果收益上限 ≤ 0.18 PPL。**
Trial 8（无 PCAM，结构上 Δ≡0）Test PPL = 32.97；Trial 9（含 Δ）= 32.79。推理期掐断 Δ 的代价为 +5.30，其中 **≥96% 属推理期分布失配代价**，不可计入 Δ 的信息价值。上一版报告"微扰项存在显著正向增益"的结论作废。

**纠偏 2：外层 LN 不是架构级承重墙。**
Trial 8 中 Generator 直接接收未归一化隐状态（std≈1.01）并稳定收敛至 32.97，证明架构不依赖外层 LN。模式 C 的 +49.67 中 **≥99.6% 属尺度失配（1.62→1.01）代价**。正确结论：外层 LN 仅定义了 Trial 9 旧权重下的输入分布，旧权重不可热插拔去 LN；**这不构成否决无 LN 恒等架构从头重训的理由**。

### 4. 2×2 析因分析

| 项 | 值 |
| :--- | :---: |
| Δ 效应（LN 域内）$A-B$ | −5.3001 |
| Δ 效应（裸残差域）$D-C$ | +0.2201 |
| 纯 LN 效应（无 Δ）$B-C$ | −44.3681 |
| 交互项 $(A-B)-(D-C)$ | −5.5202 |

**解读限定**：C 与 D 同处尺度崩溃区（PPL ≈82），该区间内 $D-C=+0.22$ 无信噪比，**不可据此断言 Δ 在无 LN 条件下具备劣质属性**。可靠表述为：Δ 的效应只能在 LN 维系的尺度域内被有效测量。

### 5. 多样性配对检验

| 模式 | Dist-2 |
| :---: | :---: |
| A | 17.76% |
| B | 16.78% |
| 配对差 | +0.8632%，95% CI [+0.2278, +1.5461] |

CI 不含 0（确定性事实）。但该落差与 PPL 恶化 5.30 同源，**很大程度上是推理期切断微扰导致的解码退化，不可独立夸大为 Δ 对多样性的纯增益**。

## 二、DPFC 离线后验融合与双重 McNemar 检验

### 1. 概念澄清：NCM 的温度系数是伪参数

$\arg\max_c(\mathrm{sim}/\tau) \equiv \arg\max_c(\mathrm{sim})$ 对任意 $\tau>0$ 成立，NCM-only 的分类决策与 τ 无关。τ 仅在融合（概率凸组合 / logit 尺度竞争）中有效。

### 2. 测试集冻结评测

| 分类器 | 超参 | Test Acc | Δ | Dev Acc |
| :--- | :--- | :---: | :---: | :---: |
| 纯 Linear | α=0 | 41.20% | 0.00% | 44.04% |
| 纯 NCM | 任意 τ>0 | 40.00% | −1.20% | 43.23% |
| DPFC 融合 | α=0.5, τ=0.5（logit） | 40.93% | −0.27% | 44.33% |

### 3. 双重 McNemar 检验（n=5255）

| 检验 | 列联表 (a,b,c,d) | χ² | p | 判定 |
| :--- | :--- | :---: | :---: | :--- |
| NCM vs Linear | 1969, 196, 133, 2957 | 11.6839 | 6.304e−4 | **显著负** |
| DPFC vs Linear | 2121, 44, 30, 3060 | 2.2838 | 0.1307 | 不显著 |

**结论**：冻结表征下，软聚类原型不具备超过线性头的判别力，且离线后验融合引入轻微负迁移。Dev 上 DPFC 领先 Linear（44.33 vs 44.04）而 Test 上反向（40.93 vs 41.20），是 Dev→Test 落差（约 2.8pp）大于调参增益（0.29pp）的典型过拟合表现。

### 4. NCM 判别力弱的病因

原报告将 NCM 弱单一归因于 `--use_arc_margin` 缺失不成立（反证：启用 margin 的 V8.2 F Test EMO Acc = 40.97%，低于未启用的 V9 Trial 7 = 42.25%）。

更直接的机理：MCP 模式下 `class_aware_uniformity_loss` 仅作用于**样本投影** `proj_norm`，原型矩阵本身无任何类间斥力约束（[model.py:467-470](../../../src/models/CASE/model.py)）；EMA(μ=0.96) 质心是类条件期望而非判别最优中心。与 DBI 6.05、Silhouette −0.03 的既有观测一致。

## 三、验证集批次重组噪声实测（本轮新增）

### 1. 缺陷事实

`data_loader_val` 被配置为 `shuffle=True` + `batch_size=config.batch_size`（[loader.py:1398-1403](../../../src/utils/data/loader.py)），而 [common.py](../../../src/models/common.py) 对 PPL/EMO_loss 采用**批次级宏平均**聚合。因此验证指标是随机实现值，不可复现。

### 2. 实测结果（10 轮 dev / 2 轮 test，多种子）

| 指标 | 均值 | 标准差 | 极差 | 区间 |
| :--- | :---: | :---: | :---: | :--- |
| dev macro_PPL | 37.7961 | 0.0610 | **0.2142** | [37.7111, 37.9252] |
| dev micro_PPL | 38.1229 | 0.0039 | 0.0112 | [38.1185, 38.1296] |
| dev EMO_loss | 2.2454 | 0.0018 | 0.0066 | — |
| dev Score | 49.0230 | 0.0641 | **0.2152** | [48.9382, 49.1534] |
| test macro_PPL | 32.7774 | 0.0000 | 0.0000 | 确定性 |
| test micro_PPL | 39.2672 | 0.0000 | 0.0000 | 确定性 |

### 3. 结论

1. **test 阴性对照通过**（极差 0）：测量体系无未知随机源，判别有效。
2. **批次重组噪声极差 0.2142 = Trial 9 遴选裕度（0.0517）的 4.14 倍**；单次实现标准差 0.0610 已超过该裕度。复合评分极差 0.2152 = 评分裕度（0.1258）的 1.71 倍。
3. **V9 历史上所有 Trial 的 `composite_best` 遴选均运行在该噪声之上**，"最优检查点"的判定存在随机性。
4. micro（token 级加权）口径把噪声压缩约 19 倍（0.2142 → 0.0112），但仍非严格零；残余来源未查明（疑为不同批次内容触发不同 GPU kernel 路径）。**micro 是改进口径，但不能承诺"确定性"。**
5. 10 轮采样不足以刻画分布尾部：训练日志的 37.7145 落在区间下沿（距 min 0.0034），而首次离线复算的 37.6461 **落在区间之外**。因此"0.0684 完全由 shuffle 解释"这一结论由量级对比（判据 2、3）支撑，不依赖单点归属。

## 四、PPL 指标口径发现（本轮新增）

| 数据集 | batch_size | macro（样本/batch 等权） | micro（token 级加权） | 差值 |
| :--- | :---: | :---: | :---: | :---: |
| Valid | 32 | 37.80 | 38.12 | 0.32 |
| Test | **1** | **32.7774** | **39.2672** | **6.49** |

**根因**：test 的 DataLoader 固定 `batch_size=1`，此时 macro 聚合等价于**样本级平均**（短回复等权放大，而短回复更易预测）；valid 的 `batch_size=32` 使 macro 已近似 token 级平均。两者口径不同。

**影响**：
1. 历史文档反复引用的"验证→测试 PPL 落差 5.14~5.46"（[v9_experiment_log.md:423](../v9_experiment_log.md)）**主要是口径差异，不是泛化差距**；
2. 用该"落差"外推未实测检查点的 Test PPL 的做法，其经验稳定性尚可，但物理解释错误，应停止使用；
3. 真实可比的泛化差距为 test micro 39.27 vs dev micro 38.12 = **+1.15**；
4. Test PPL 32.79 与历史 Trial 同口径（均为 batch=1 macro），**横向比较依然有效**；但与外部文献的 token 级 PPL 不可直接比较，论文表述必须注明口径。
