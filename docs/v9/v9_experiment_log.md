## 0. V9 课题总览与硬件跨越背景

- **立项基底**：V8 全周期收官（旗舰版 V8.2 F 斩获历史最优生成质量：Test PPL **32.83**，Greedy Dist-2 **16.79%**，Sampling Unique **98.60%**，EMO_acc **40.97%**，Alignment **0.9514**）。
- **硬件升级环境**：从本地 RTX 3050Ti (4GB) 跨越至 AutoDL 云端单卡 NVIDIA GeForce RTX 4090D (24GB 显存, CUDA 12.1, PyTorch 2.1.0, Python 3.10)。
- **核心解决矛盾**：
  1. **小批次负样本池受限**：原 4GB 下单步 Batch=8，每步约 24~27 个情感类别未被抽样，MCP 动量更新稀疏，EMA 轨迹阶跃抖动；
  2. **强制 AMP 精度妥协**：4GB 下为防 OOM 必须依赖 FP16 混合精度；24GB 环境下彻底解绑，回归 FP32 原生全精度高保真梯度反向传播；
  3. **吞吐瓶颈突破**：正式训练吞吐由 0.70 it/s 暴增至 2.83 it/s（真实样本吞吐提升 16.1 倍）。
- **第一不可逾越红线**：
  **坚决捍卫对话生成质量，Test PPL ≤ 32.83 为全生命周期第一核心红线**。

> **【口径注记 · 2026-10-19 · 原文保留，数值不改】** 本节（含下方 §1 目标矩阵 `≤ 32.83` 一行）是 **V9 立项期原文**。其 `32.83` 取自 V8.2 F 旗舰的 Test PPL，而 V8 评测口径为 **batch_size=16**（`save/epcl_v8_2_f/eval_pipeline.log:32`），V9 评测固定 **batch_size=1**（[loader.py:1423-1428](../../src/utils/data/loader.py#L1423-L1428)）。**跨口径直接比较违反铁律 III**，故 `32.83` 不可作为 V9 的可比红线阈值：T9 的 32.79（b=1）在数值上「低于」32.83（b=16），但那是口径差异，不构成对 V8.2 F 的超越（详见 [v9_trial10_cloud_analysis.md](reports/v9_trial10_cloud_analysis.md) §五之二、B3 项）。

#### 三、双重致命致因深度剖析 (Post-Mortem Analysis)

##### 1. [代码逻辑缺陷] 历史遗留 `iters = 20000` 强行拦截了成熟期黄金权重落盘
- **缺陷定位**：`main.py:63` 定义 `iters = 20000`，并在 `main.py:154-155` 中执行：
  ```python
  model.train()
  if n_iter < iters:
      continue
  ```
- **物理后果**：原版 ACL 2023 用于小批次慢预热的逻辑在重构时未被清理。在前 20,000 步内，每一次验证评估后的早停监控、复合评分记录以及 `model.save_model` 逻辑被全部无条件跳过；
- **直接恶果**：模型在 Step 5,000 ~ 6,000 步达到全生命周期最佳状态（PPL ~42, EMO_loss ~2.15, EMO_acc ~41.5%）时，系统**完全没有保存该权重**。直至第 22,000 步跨过 20,000 门槛后才开始保存，但此时模型已严重过拟合，连续 10 次未能突破 22k 步的分值，最终早停退出并拿第 42k 步的劣质权重进行了测试。

##### 2. [训练动力学错配] 批次放大 8 倍后未等比压缩训练步数，模型强跑 138 个 Epoch
- **物理尺度转换**：ED 训练集仅包含 19,533 个对话样本。
  - 在 4GB 环境（单步 8）下，1 个 Epoch 需 2,441 步，跑 40,000 步等价于 **约 16.4 个 Epoch**；
  - 在 24GB 环境（等效全局 Batch 64）下，1 个 Epoch 仅需 **305 步**；
  - 跑 42,000 步，相当于模型在同一个 1.9 万条样本的小数据集上反复强行训练了 **137.7 个 Epoch**！
- **过拟合铁证**：自回归语言模型在同一个文本集上迭代 138 轮，必然导致训练集 PPL 降至 3.53 的病态记忆化，词表概率分布极度尖锐，泛化能力彻底崩塌；
- **真实物理波谷验证**：模型在等效 Batch 64 下的最佳收敛点正好在 **Step 5,000 附近**（$5000 / 305 \approx 16.4$ 个 Epoch，与 V8 物理周期惊人一致！）。

#### 四、核心学术定论与积极信号
1. **密集动量原型（Dense-MCP, $\mu=0.96$）完全验证**：`epcl_loss` 光滑衰减至 0.089，证明在大批次充分负样本下，原型对比学习空间高度平稳收敛；

#### 一、真实学术评测指标 vs 评测流水线失真审计

在训练收尾阶段，`main.py` 内部原生调用测试与独立 `eval_pipeline.py` 输出产生了剧烈的数据分歧：

| 评估维度 | 原生测试输出 (`v9_trial2_results.txt`) | 独立流水线输出 (`v9_trial2_eval.txt` / JSON) | 状态诊断 |
| :--- | :---: | :---: | :--- |
| **Test PPL** | **35.6281** | 52.41 | **原生为真实性能，流水线受噪声毒化** |
| **Test EMO_acc** | **40.30%** | **2.99%** | **流水线分类头未初始化，退化为随机猜** |
| **Test EMO_loss** | **2.0530** | 3.8839 | 对应随机猜测交叉熵 $-\ln(1/32) \approx 3.46$ |
| **Test BOW_loss** | **5.3967** | 5.3967 | 完全一致 (主干与词表特征一致) |
| **Test MIM_loss** | **1.1378** | 1.1378 | 完全一致 (上下文与概念互信息一致) |

##### 根因确诊：`eval_pipeline.py` 硬编码残差分类头导致权重漏载
1. **训练时真实结构**：`main.sh` 未开启 `--emotion_head_type`，默认使用单层线性分类头 `linear`；
2. **评测时代码写死**：`eval_pipeline.py:148` 写死 `config.emotion_head_type = "residual_mlp"` 与 `config.use_pcam = True`；
3. **严重恶果**：评测时实例化了双层 MLP 分类头，由于检查点只有单层 `linear` 权重，`load_state_dict(..., strict=False)` 忽略缺失键，导致评测分类头完全是未经训练的高斯随机初始化！32 类随机盲猜概率正好为 $1/32 = 3.125\%$（与 2.99% 严格契合），未对齐的分类头隐状态反向注入解码器，使 PPL 从 35.63 恶化到 52.41；
4. **修复实施**：已在 `eval_pipeline.py` 中引入 state_dict 权重键值动态预检，自适应匹配网络拓扑，彻底杜绝此类乌龙。

#### 二、硬件升级与模型指标的科学辩证 (为什么硬件更新没有带来指标“自动暴涨”？)

硬件升级（RTX 4090 24G）解决了算力、显存与通信吞吐量问题，但深度学习模型的泛化指标取决于**优化动力学与超参数尺度的系统性对齐**：
1. **大 Batch (64) 的尖锐极小值陷阱 (Sharp Minima)**：
   - 小 Batch (8) 具有较大的随机梯度噪声，天然具备类似于退火的隐式正则化效应，有助于跳出尖锐极小值；
   - 大 Batch (64) 梯度信噪比高，若学习率未配套余弦退火平滑降温，模型容易收敛于尖锐局部极小，导致自回归生成的 Test PPL 难以下探。
2. **致命断档：学习率退火全程未触发（水平死线 $8.139 \times 10^{-4}$）**：
   - 历史代码将退火绑定在 `is_currently_frozen and iter > epcl_freeze_step`；
   - 默认 `epcl_freeze_step=14000`，而大批次总步数已缩减至 10,000 步，导致整个训练期 `should_decay` 恒为 `False`！
   - 模型在 Step 5,000 ~ 8,000 步一直以 $8.139 \times 10^{-4}$ 的极大学习率在局部盆地周围高频剧烈震荡，无法精细收敛至平坦最优谷。
3. **偏置退火过晚干扰生成自由度**：
   - 词表偏置退火起点设在 `bias_anneal_start=5000`（相当于第 16 个 Epoch），过晚退火使解码器在成熟期仍受强偏置硬性约束，限制了语言流利度。

#### 三、流形散点图 (`v9_trial2_manifold.png`) 原型大量聚集的几何成因剖析

针对流形图中原型大量堆叠在一块、缺乏类内聚集与类间分离的现象，审计确诊以下三大底层根因：
1. **评测伪流形失真**：
   - 绘制流形图时使用的是未经初始化的随机残差 MLP 隐状态，计算出的 Silhouette 轮廓系数为负值 (-0.0856)，呈现的是被随机投影打碎的虚假流形；
2. **MCP 原型模式下 `uniformity_loss` 被硬性置零**：
   - 查证 `src/models/CASE/model.py:467-470`：当 `use_mcp=True` 时，代码显式指定 `loss_uni = torch.tensor(0.0)`！
   - 原型作为不可导 Buffer 完全由样本重心 EMA 驱动，自身没有超球面斥力；
   - 而 EmpatheticDialogues 数据集各类情感对话存在大量的共通先验上下文（共情模板），在缺乏超球面均匀排斥力的情况下，样本重心本身就向流形中心靠拢，导致 EMA 质心原型全部堆缩在一块；
3. **解法落地：样本级超球面均匀度排斥 (Sample-level Uniformity)**：
   - 原型 Buffer 虽不可导，但样本投影特征 `proj_norm` 完全可导；
   - 已在 `PrototypeContrastiveLoss` 中实现 `sample_uniformity_loss(proj_norm)`：通过在可导样本点云间施加高斯排斥势能，强力推开特征空间，阻止特征塌缩，进而驱动 EMA 原型在超球面上均匀辐射散开。

### [Phase 3] V9 Trial 3: 优化冲刺与终极红线突破部署

针对 Trial 2 暴露的瓶颈，Trial 3 执行以下四大工程升级：

1. **学习率调度与分类头解绑，激活大批次余弦退火**：

3. **检查点遴选偏向分类损失**：实际生效的 α=8 惩罚上述 EMO_loss 上升，选中 7499 而非 Valid PPL 更低的 8999（−0.31）。按 T6 数据反推，α < 1.65 时会选中 8999；按 T4/T5/T6 的验证→测试 PPL 落差 5.14~5.46 估算，8999 的 Test PPL 约 33.0~33.3（估算值，未实测）。
4. 训练段 BOW 5.56~5.59、KL ≈0.028、Valid MIM 1.056~1.085 全程平稳。

#### 五、机理分析

##### 1. EMO_acc 41.88%：项目最高测试值，但不构成可归因的机制突破

- **统计分辨率**：n=5,255 时测试准确率标准误 ≈ √(0.419×0.581/5255) ≈ 0.68pp；两个独立模型差值的标准误约 0.96pp。T6−T4 = +1.06pp，约 1.1 个标准误（双侧 p≈0.27），**未达显著**。配对 McNemar 检验可更精确，但 `results.txt` 未输出逐样本预测标签，当前无法执行。
- **验证集反向证据**：同为 Step 7499 的检查点，T6 Valid Acc 43.28% **低于** T4 的 43.78%（−0.50pp），Valid PPL 也略差（+0.11）。验证集与测试集方向相反，说明这 1.06pp 主要落在检查点决策边界的随机波动范围内。T4 的验证-测试 Acc 落差为 2.96pp，T6 为 1.40pp，这一落差本身的波动也属于噪声量级。
- **与观测一致的假设（待多种子验证）**：`cls_anchor=default` 跟随 `epcl_anchor=fine_emotion`，即分类头输入与 EPCL 锚点是同一表征。α_uni 降低后，类间斥力减弱，对近义类样本的强制分离减少，表征几何更平滑：CHI +19.6%、DBI −6.9%、Offset −4.5%、Alignment +0.0054。但 Silhouette 同时变差（−0.0272→−0.0328），即改善发生在**类重心离散度**层面，而非样本级可分性层面，不足以解释分类准确率的真实提升。
- **结论**：41.88% 记为"单种子观测值"，在 ≥3 种子复现前不作为机制性结论写入论文。

##### 2. Test PPL 33.62：T4→T6 退步 0.43 同样在噪声范围内

- Valid PPL 仅差 0.11，Test PPL 差 0.43；T4/T5/T6 的验证→测试落差在 5.14~5.46 之间波动 0.32。**单种子下小于约 0.4 的 Test PPL 差异无法判定方向**。
- T5→T6（退火 8000→6000 步）Test PPL −0.46、Valid PPL −0.63，方向一致，说明"更快走完退火"在当前 10k iter 生命周期内有效，与第四节第 1 条一致。

##### 3. 流形对齐

Alignment 0.9344、Offset 0.3514 均为 V9 最优，仍未回到 V8.2 F 的 0.9514；DBI 5.94 为 V9 最优，但劣于 CASE 原版 5.65 与 V8.2 F 4.78。在 α_uni 0.8~1.5 区间内，Silhouette 始终为负，class-aware uniformity 没有建立样本级类簇结构。

##### 4. 生成多样性

Greedy Dist-2 18.00% 为 V6~V9 最高，Beam Dist-2 11.19% 显著高于 V8.2 F。Beam Unique 仅 33.0%，抽样中 Beam 输出大量重复 "i am sorry to hear that ."；Greedy 存在语义不通样例（如 "well , at least you are not a good thing ."）。Dist/Unique 只衡量词汇多样性，不衡量相关性与连贯性，需补充参考相关性指标。

- 微扰相对模长 $\|\Delta h\| / \|h_t\| = \mathbf{9.72\%}$；隐状态标准差 $\mathrm{std}(h_t) = \mathbf{1.0128}$；外层 LN 输出标准差 $\mathrm{std}(\mathrm{LN}) = \mathbf{1.6196}$；

#### (3) 因果纠偏结论（铁律 I 约束）
- **因果纠偏 1（微扰 $\Delta$ 的训练期增益上限 $\le 0.18$ PPL）**：
  推理期掐断 $\Delta$（模式 B）恶化 $+5.3001$ PPL，但真实的训练期消融对照（Trial 8 无 PCAM $\to$ Trial 9 含 PCAM）的测试 PPL 仅提升 $32.97 \to 32.79$（$\mathbf{0.18}$ PPL）。差值中 **$\ge 96\%$ 属于推理期分布外（OOD）协变量破坏代价**，不可计为 $\Delta$ 的因果增益。
- **因果纠偏 2（外层 LayerNorm 非架构承重墙）**：
  推理期移除外层 LN（模式 C）导致 PPL 暴跌至 82.45（$+49.67$），但 Trial 8 证明生成器直接接收未归一化隐状态（std $\approx 1.01$）能稳定收敛至 32.97。模式 C 恶化中 **$\ge 99.6\%$ 属于方差尺度失配代价**（1.62 $\to$ 1.01）。外层 LN 仅定义了当前权重的输入分布，旧权重不可热插拔去 LN，但这并不构成否决恒等重构架构从头训练的依据。
- **2×2 析因与交互项分析**：
  $(A - B) = -5.3001$（LN 域内），$(D - C) = +0.2201$（裸残差域），交互项为 **$-5.5202$**。表明 $\Delta$ 的正向调节效应只能在 LN 维系的方差尺度域内被有效测量；C 与 D 同处尺度崩溃区（PPL $\approx 82$），不可据此断言 $\Delta$ 在无 LN 条件下具备劣质属性。

### 3. DPFC 离线后验融合与双重 McNemar 显著性检验

#### (1) 判别基准与伪参数澄清
$\arg\max_c(\mathrm{sim} / \tau) \equiv \arg\max_c(\mathrm{sim})$ 对任意 $\tau > 0$ 恒成立。纯原型分类器（NCM-only）的预测结果在数学上与平滑温度 $\tau$ 完全独立，$\tau$ 在非融合场景下为伪参数。

#### (2) 测试集（5,255 样本）冻结表征评测

| 分类器 | 判别依据与超参 | Test Acc | Δ vs Linear | Dev Acc |
| :--- | :--- | :---: | :---: | :---: |
| **线性分类头 (Linear)** | 原始分类头 ($\alpha = 0$) | **41.20%** (2165/5255) | 基准 | 44.04% |
| **最近原型分类器 (NCM)** | 原型余弦相似度（任意 $\tau > 0$） | **40.00%** (2102/5255) | **-1.20pp** | 43.23% |
| **后验融合 (DPFC)** | Logit 融合 ($\alpha = 0.5, \tau = 0.5$) | **40.93%** (2151/5255) | **-0.27pp** | 44.33% |

#### (3) 双重 McNemar 配对卡方检验

| 检验组合 | 统计量 $\chi^2$ | $p$ 值 | 样本列联表 $(n_{00}, n_{01}, n_{10}, n_{11})$ | 检验判定 |
| :--- | :---: | :---: | :---: | :--- |
| **NCM vs Linear** | **11.6839** | $\mathbf{6.304 \times 10^{-4}}$ | $(1969, 196, 133, 2957)$ | **极显著劣于线性头** |
| **DPFC vs Linear** | **2.2838** | $\mathbf{0.1307}$ | $(2121, 44, 30, 3060)$ | **无显著差异（净亏 14 例）** |

- **机理诊断**：在表征冻结条件下，软聚类原型并不具备优于线性头的判别边界；离线融合在测试集上产生微弱负迁移。Dev 上 DPFC 领先（44.33% vs 44.04%）而 Test 上反向落后，属于 Dev 到 Test 固有泛化落差（约 2.8pp）掩盖超参调优增益（0.29pp）的过拟合现象。
- **病因定位**：MCP 模式下 `class_aware_uniformity_loss` 仅约束样本投影 `proj_norm`，原型矩阵自身缺乏显式类间斥力约束（DBI 6.05，Silhouette −0.03）；动量更新（$\mu=0.96$）计算的是类条件期望，而非判别最优中心。
- **决策结论**：**彻底否决将 DPFC 作为主推创新点**。
