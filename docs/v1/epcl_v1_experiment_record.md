# CASE-EPCL 融合实验 (v1) 记录与架构分析

> **实验日期**: 2026-07-24
> **实验分支**: main (EPCL v1 注入版)
> **环境限制**: RTX 3050 (4GB VRAM) / 强制 AMP 混合精度 / 梯度累加
> **数据集**: EmpatheticDialogues (ED)

---

## 1. 实验背景与动机

本次实验（v1）的**核心目标**是验证将全局“原型对比学习 (EPCL)”引入以局部互信息最大化 (MIM) 为主导的 CASE 模型后，两种表征学习机制的**正交性**与**互补性**。

为了在 4GB 显存下完成训练，实验采用了 `batch_size=8`，因此触发了超参数自适应缩放（将原本的步数均扩大两倍）：
*   `epcl_warmup`: 6,000 步
*   `warmup` (Noam): 24,000 步
*   `epcl_freeze_step`: 28,000 步（避免分类头冻结过早导致崩溃）

## 3. 实验现象诊断：为什么多样性未见爆发？

根据 TensorBoard 的观测，**`epcl_loss`（InfoNCE 损失）呈现了极其平滑且完美的收敛曲线（2.7 → 2.2）**。这表明，EPCL 的原型矩阵和投影网络（Projection Head）完全生效，正在拉开特征的对比流形。
但在最终产出的文本和 PPL 维度上，EPCL 并没有显著影响解码器的分布。这种“损失降了但表现没变”的现象，揭示了复杂的底层架构博弈：

### 3.1 投影头屏蔽效应 (The Projection Head Shielding Effect)
本实验在 `emotion_enc` 节点上接入了 EPCL 模块，该模块附带了一个高容量的非线性投影头（MLP）。
在梯度反向传播时，由于底层的 `emotion_enc` 已经背负了巨大的负荷（需兼顾语义生成和 MIM 对齐约束），模型采取了一种“偷懒且聪明”的优化策略：
**它让高层的 MLP 投影头吸收了所有的拓扑变形任务（满足了 EPCL Loss 的下降），而“保护”了底层的 `emotion_enc` 骨干网络不发生形变。** 结果导致解码器看到的特征跟 Baseline 几乎毫无差异。

### 3.2 局部互信息 (MIM) 与 全局原型 (EPCL) 的“特征拥挤”冲突
在原版 CASE 中，MIM loss 是通过实例级的对比来锚定认知与情感图谱的对齐。
- **正交性验证成功**：EPCL 与 MIM 被证明是**绝对正交兼容**的，叠加两种极端的对比学习策略并未引发梯度爆炸，生成连贯性（PPL 34.69）稳定保持了论文的高水准。
- **互补性发挥受限**：由于硬件妥协（AMP + 梯度累加）导致的流形空间狭窄，`emotion_enc` 无法在同一维度上同时处理局部的实例区分（MIM）和全局的类别排斥（EPCL）。梯度冲突导致 EPCL 被边缘化。

## 4. 结论与后续演进方向 (v2 展望)

### 核心结论
本次 v1 实验为论文贡献了不可多得的**深度架构消融分析 (Ablation Insights)**。我们证明了“单纯在融合瓶颈处粗暴叠加对比损失，会被模型的投影头吸收而无法传导给解码器”。

### v2 迭代方向
针对“屏蔽效应”，在接下来的实验优化中可以尝试以下方向：
1. **穿透式锚定 (Decoder-Side Anchoring)**：跳过 `emotion_enc` 融合层，将 EPCL 的对比对象下沉到解码器的 Cross-Attention 状态流中，直接强迫解码器的隐状态拉开距离，而不是在编码器端做“隔靴搔痒”。
2. **消融 MIM 测试**：考虑到两者的冲突，可以进行一次 `config.coarse_weight = 0` 及 `config.fine_weight = 0` 的消融实验，关闭 MIM，让特征流形完全被 EPCL 主导，验证其极限多样性潜力。
3. **消除 Projection Head 隔离**：在计算 InfoNCE 距离时，尝试移除非线性 MLP 映射层，让 EPCL 的梯度“硬生生”地撕扯骨干表征，逼迫解码器感受多样性张力。
