# CASE-EPCL 项目理论学习指南与 Prompt 手册

本指南专为非科班/零理论基础的研究者设计。请开启一个新的对话，并严格按照以下阶段和 Prompt 依次提问，由浅入深地完成理论体系的补齐。

## 核心建议调用的 AI Skills
在新对话开始时，建议主动要求 AI 挂载以下 Skill 以达到最佳教学效果：
1. **`explain-like-socrates`**：采用苏格拉底式启发教学，避免一味灌输，强迫你通过互动理解核心概念。
2. **`claude-scientific-skills`**：增强 AI 在论文解析、方法论拆解上的专业度。

---

## 阶段一：建立“自然语言生成（NLG）”与“多样性”的直觉
**目标**：理解为什么传统的语言模型会变成只会说 "I am sorry" 的复读机。

**Prompt 1（复制并发送至新对话）：**
```text
@explain-like-socrates @claude-scientific-skills 
你好，我是一个没有任何科研和深度学习基础的新手。我正在做一个关于“共情对话生成（Empathetic Dialogue Generation）”的项目。
请用极其通俗的大白话，最好结合日常生活的例子，分步解答以下问题：
1. 语言模型（比如 Seq2Seq 或 Transformer）是怎么“吐出”下一个词的？（请解释 Softmax 和概率分布的概念）
2. 为什么对话模型极度容易生成 "I am sorry to hear that" 这种万能的安全回复？（这在学术上叫什么问题？）
3. 学术界通常用什么指标来衡量“模型说话是不是复读机”？请向我解释 Distinct-1/2 指标的具体物理意义。
记住：绝不要列一堆公式给我，确保我每一步都听懂了再继续。
```

---

## 阶段二：攻克 CEM 与 CASE 的核心差异
**目标**：理解当前代码库 `CASE` 的祖师爷 `CEM` 是什么，以及 `CASE` 为什么要改进它。

**Prompt 2（复制并发送至新对话）：**
```text
现在，我需要你帮我梳理两篇顶会论文的核心演进逻辑。
背景：
第一篇是 CEM (ACL 2021): "Empathetic Response Generation via Recognizing Latent Emotion Contexts"
第二篇是 CASE (ACL 2023): "Coarse-to-Fine Cognition and Affection model"

请用通俗的语言回答：
1. 传统的对话系统缺乏常识，CEM 是怎么把外部的“常识图谱（ConceptNet）”塞进模型的？（提示：外部记忆和注意力机制）
2. CASE 觉得 CEM 有什么缺陷？（提示：粗粒度 vs 细粒度）
3. CASE 提出了一个叫 "互信息最大化 (MIM, Mutual Information Maximization)" 的东西来进行“对齐”，它的直观物理意义是什么？举个例子说明。
```

## 阶段三：理解我们的终极杀器 —— EPCL（原型对比学习）
**目标**：理解为什么在 CASE 的基础上，我们还要强制植入 EPCL 模块，以及对比学习的本质。

**Prompt 3（复制并发送至新对话）：**
```text
非常好。现在来到了我这个项目的核心创新点：EPCL (Emotion Prototype Contrastive Learning，情感原型对比学习)。
在我目前的实验中，CASE 虽然把 PPL（困惑度）降得很低，但是生成出来的回复多样性极差（大量安全回复）。

请为我解释：
1. 什么是“隐空间（Latent Space）的特征坍缩/挤压”？
2. 什么是“对比学习（Contrastive Learning）”？请用“在一群人中找双胞胎”的例子来直观解释 InfoNCE 损失函数的作用。
3. 什么是“原型（Prototype）”？
4. 结合以上三点，为什么我们在神经网络分类头（Linear层）之前插入 EPCL 模块，强制把不同情感类别的特征“推开”（Push away）并在类别中心“聚拢”（Pull together），就能彻底解决安全回复（多样性坍缩）的问题？
```

## 阶段四：科研实验设计（方法论把关）
**目标**：理解在论文里，你应该怎么向审稿人证明你的模块是有效的。

**Prompt 4（复制并发送至新对话）：**
```text
为了向导师或审稿人证明我的 CASE + EPCL 是有效的，我需要设计实验。
我已经有了 Baseline (只有 CASE 的版本) 的数据。
请告诉我：
1. 什么是消融实验 (Ablation Study)？我应该如何设计对照组？
2. 在对比学习中，为什么我们往往需要采用“两阶段训练”（比如前 14000 步冻结分类头，只让对比学习排布特征空间，之后再放开）？这背后的直觉是什么？
3. 如果审稿人问：“EPCL 和 CASE 现有的 MIM 对齐模块会不会冲突？”，我应该如何从“全局特征聚类” vs “样本内部对齐”的正交性（互补性）角度来反驳？
```

## 阶段五：连接理论与工程（我们到底在哪里动刀？）
**目标**：理解理论是如何对应到真实 PyTorch 代码和数据集上的。

**Prompt 5（复制并发送至新对话）：**
```text
现在我已经理解了你们的理论。请结合我正在使用的 EmpatheticDialogues (ED) 数据集，解答以下工程概念：
1. 我们的数据长什么样？（上下文 Context、情感标签 Emotion、回复 Response，它们是如何映射到模型的输入和输出的？）
2. 在 CASE 模型的代码逻辑中，有一个叫做 `emotion_enc` 的隐藏层变量。它混合了“常识网络”和“情感词汇网络”的特征。为什么 EPCL 的投影头（Projection Head）和对比损失（Contrastive Loss）必须挂载在这个 `emotion_enc` 节点上，而不是加在最开始的词嵌入，或者最后的解码器上？
3. 在对比学习中，我们经常说“温度超参数（Temperature, τ）”。它在拉开特征距离时起什么物理作用？如果 τ 设置得太大或太小会怎样？
```

假如我是这篇文章的一作，准备把“CASE + EPCL”写成一篇论文。
请为我列出一个典型的计算机顶会（如 ACL / EMNLP）学术论文大纲。
并重点教我：

2. 如果审稿人质疑：“你只是把对比学习生搬硬套到了 CASE 上，这算什么创新？”，我该如何用“正交互补性（Orthogonal Complementarity）”和“双视角对齐（Local vs Global）”这两个高级学术概念来撰写防御性的 Rebuttal（反驳）？
