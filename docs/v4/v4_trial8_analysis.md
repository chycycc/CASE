## 5. 三元平衡机制归因总结

```mermaid
graph TD
    A["α_mim: 0.5→0.1<br/>释放解码器表征容量"] --> D["Dist-2: 1.91%→5.01%<br/>词汇空间解锁"]
    A --> E["Emo Acc: 37.41%→40.34%<br/>解除情感编码垄断"]
    B["div_loss: 1.5x→2.0x<br/>温和多样性推力"] --> D
    B --> F["唯一率: 35.9%→56.0%<br/>长尾分布健康化"]
    C["LR 衰减: 3.125e-4→1e-5<br/>28k步后线性降温"] --> G["PPL: 34.93→33.82<br/>CTX最低=泛化最优"]
    C --> H["Val PPL: 收敛至46k步<br/>解锁后半程学习潜力"]
```

| 干预变量 | 主要受益指标 | 机制解释 |
| :--- | :--- | :--- |
| **α_mim 0.5→0.1** | Dist-2 (+163%), Emo Acc (+7.8pp) | 解除解码器情感编码对表征容量的垄断，词汇空间从被锁死的窄带恢复至正常工作宽度 |
| **div_loss 1.5→2.0** | 唯一率 (+56.1%), Dist-1 (+85%) | 在 α_mim 释放空间后，适度推力引导模型探索更多词汇组合，但避免了 3.0x 时的过拟合 |
| **LR 线性衰减** | PPL (−3.2%), Val PPL 持续收敛 | 遏制后半程高 LR 引发的参数震荡，CTX Loss 达到全周期最低 3.521 |
