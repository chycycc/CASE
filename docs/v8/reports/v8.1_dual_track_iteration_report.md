## 一、双轨实验设计与理论方案

### 1. 核心任务定位与反思
- **学术优先原则**：本课题的核心目标是“高质量共情回复文本生成（低 PPL、高多样性 Distinct-1/2）”，情感分类（CE）与原型对比（EPCL）属于多任务辅助约束，维持在 40.0% 基准线即可，避免为盲目刷高分类准确率而牺牲生成性能。
- **历史痛点**：
  1. **硬冻结脱节**：第 28,000 步硬锁死分类头参数（`requires_grad=False`），导致后半程编码器自适应微调使分类头脱节，测试集 EMO_acc 下滑至 39.39% ~ 39.66%；
  2. **缺乏显式偏置**：解码器词表输出仅依赖自回归隐层，高质量原型对齐向量未直接作用于词表预测概率。

---

### 2. 方案一：路线 A（端到端多任务平衡 + 词表层情感偏置注入）
- **核心机制**：
  - 彻底取消硬冻结（`--disable_freeze`），保持分类头全程联合微调；
  - 借鉴 KEMP (AAAI 2022) 思想，将 Arc-EPCL 300 维全局共情表征 $emotion\_enc$ 经由可学习门控直接映射至词表空间作为先验偏置：
    $$\text{logit} = W_{\text{vocab}}(H_{\text{pre}}) + \sigma(\text{gate}) \cdot W_{\text{emo}}(emotion\_enc)$$
- **代码实现 (`src/models/CASE/model.py`)**：
  ```python
  # 解码端情感词表偏置投影层
  self.emo_to_vocab = nn.Linear(config.hidden_dim, config.vocab_size)
  self.emo_bias_gate = nn.Parameter(torch.tensor(-2.0))  # sigmoid(-2) 约 0.119

  # 前向解码预测注入
  emo_vocab_bias = self.emo_to_vocab(emotion_enc).unsqueeze(1)
  logit = self.projector(pre_logit) + torch.sigmoid(self.emo_bias_gate) * emo_vocab_bias
  ```

---

### 3. 方案二：路线 B（平滑余弦软退火解耦 + 复合早停）
- **核心机制**：
  - 废除硬冻结，在 24k ~ 40k 步期间通过余弦平滑衰减将辅助损失权重由 1.0 降低至 0.05，既释放生成自由度，又保留微弱梯度流防范流形崩溃；
  - 验证集检查点保存引入复合判据：$\text{Score} = \text{Valid\_PPL} - 20.0 \times \text{Valid\_EMO\_acc}$。
- **代码实现 (`src/models/CASE/model.py`)**：
  ```python
  if train and iter >= 24000:
      progress = min((iter - 24000) / 16000.0, 1.0)
      soft_weight = 0.05 + 0.95 * 0.5 * (1.0 + math.cos(math.pi * progress))
  else:
      soft_weight = 1.0
  ```

## 三、隐空间流形可视化与机理剖析

### 1. 流形形态对照
- **路线 A (Trial A)**：样本表征点云与 32 类动量原型 (MCP) 呈现极高的余弦对齐度 (0.9093)，原型欧氏漂移低至 0.4182，参见 [`docs/v8/images/v8_1_trialA_manifold.png`](file:///e:/github/CASE/docs/v8/images/v8_1_trialA_manifold.png)；
- **路线 B (Trial B)**：退火后期保持微弱梯度流，流形未发生崩塌，对齐度保持在 0.8496，参见 [`docs/v8/images/v8_1_trialB_manifold.png`](file:///e:/github/CASE/docs/v8/images/v8_1_trialB_manifold.png)。

### 2. 核心学术结论
1. **词表层情感偏置注入 (路线 A) 具有全局协同优势**：
   - 实现了 **39.70%** 的分类准确率（大幅超越基线 38.64%），原型对齐度突破至 **0.9093**，证明联合微调与词表偏置使多任务梯度形成建设性叠加；
   - 贪婪解码 Unique 句子率（65.2% vs 42.4%）全面压制路线 B。
2. **遗留瓶颈与向 V8.2 演进的动因**：
   - 路线 A 存在主要缺陷：全词表全量加性偏置对无情感功能词（如 "the", "is", "a"）产生了负面底噪，推高了 Test PPL（34.26 vs 基线 33.12）；
   - 该结论直接催生了 **V8.2 稀疏拓扑偏置（Top 15% 情感实词激活，85% 功能词 Zero-Mask）** 的架构升级。
