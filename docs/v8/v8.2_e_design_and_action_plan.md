# CASE-EPCL V8.2 E 终局全量达标设计与行动方案

> **文档定位**: 针对 V8.2 D 实测中因帕累托早停权重 $\alpha=8.0$ 诱发的“检查点超早期截断锁死（Step 27,999 早产）”问题，制定退火成熟保护期（`min_save_step=32000`）、帕累托评分权重重构（$\alpha=3.5$）、分类头专属解耦锚点（`cls_anchor=fine_emotion`）以及低偏置底噪冲刺（0.15 下限）四大系统化措施，实现全部 6 项核心指标（PPL $\le 32.50$, EMO_loss $\le 2.1500$, EMO_acc $\ge 41.16\%$, Greedy Dist-2 $\ge 15\%$, Sampling Dist-2 $\ge 45\%$, 原型对齐 $\ge 0.94$）的真正同时达标。

### 1.2 关键机制矛盾剖析
1. **动态情感损失加权（1.0 $\to$ 1.5）完全正确且极其高效**：
   彻底证明了后半程赋予分类头更强的梯度对抗刚度，可以彻底消除多任务梯度侵蚀，把 EMO_loss 从 2.30 压降至 2.07。
2. **偏置退火与低学习率深水微调（35k~42k 步）是 PPL 与多样性达标的充要条件**：
   只有当步数走到 35k 步以上时，词表偏置门控预热充分（>20k）、自适应稀疏掩码动态校准稳定、语言模型在 1e-5 低学习率下精细拟合，且偏置退火衰减消除概率底噪后，PPL 才能向 32.50 冲刺，Dist-2 才能突破 16% 与 46%。
3. **D 计划的致命短板是“早停判定把时间锚点截断在了 27,999 步”**：
   在 Step 27,999 时，偏置退火根本还没有开始（退火起点是 30,000 步），模型以未退火、未充分学习的半成品状态锁死了唯一检查点。

## 二、 V8.2 E 四项精准技术措施

### 2.1 引入“退火成熟保护期”（`min_save_step=32000`）
- **代码实施**：在 `main.py` 验证集评估逻辑中，增加 `min_save_step` 判断：
  ```python
  min_save_step = getattr(config, 'min_save_step', 0)
  if n_iter < min_save_step:
      # 处于退火成熟保护期，记录过渡最优，但不计入早停耐心
      if is_score_better:
          best_score = cur_score
          best_ppl = ppl_val
      patient = 0  # 保护期强制保持耐心满格
  else:
      # 成熟期：正式遴选最终黄金检查点并开始早停计数
      if is_score_better:
          best_score = cur_score
          best_ppl = ppl_val
          patient = 0
          model.save_model(best_ppl, n_iter)
          weights_best = deepcopy(model.state_dict())
      else:
          patient += 1
  ```
- **技术效果**：从物理机制上彻底消除 32,000 步之前的检查点误判，确保最终参与测试集评测的黄金检查点一定诞生在偏置退火与语言模型收敛的成熟区间（32k ~ 44k）。

### 2.2 帕累托复合评分系数重构（$\alpha=3.5$）
- **公式**：
  $$\text{Score} = \text{PPL}_{\text{val}} + 3.5 \times \text{EMO\_loss}_{\text{val}}$$
- **数学平衡论证**：
  在成熟期内，PPL 相比 28k 步改善 1.4 点（38.51 $\to$ 37.11），而 EMO_loss 浮动约 0.25 点（2.06 $\to$ 2.31）。
  $3.5 \times 0.25 = 0.875 < 1.40$！
  成熟期低 PPL 检查点的得分（$37.11 + 3.5 \times 2.31 = 45.195$）优于早期的得分（$38.51 + 3.5 \times 2.06 = 45.720$），使得低 PPL 与低 EMO_loss 的平衡检查点能够顺利被保存。

### 2.3 分类头专属解耦锚点（`--cls_anchor fine_emotion`）
- **机理**：
  目前对比学习特征锚点挂在 `emotion_enc` 上（`--epcl_anchor emotion_enc`），而分类头直接挂在受生成自回归高量级梯度牵引的 `emotion_enc` 上，这是导致 36k 步后 EMO_loss 上浮的根本物理原因。
  指定 `--cls_anchor fine_emotion` 后，情感分类头直接挂载在由概念网络与认知网络融合生成的纯净情感特征 `fine_emotion` 上，生成任务的梯度只能通过门控极微弱地反传，彻底阻断自回归梯度对分类流形的扭曲，使得 36k~42k 步的 EMO_loss 能够长久稳定在 2.05 ~ 2.15 达标红线内！

### 2.4 偏置退火加速下探至 0.15 极低底噪 + 步数评估保护
- 保持 `--bias_anneal_start 30000 --bias_anneal_steps 10000 --bias_min_scale 0.15`；
- 在 40,000 步偏置缩放系数真正降至 0.15，彻底释放 85% 概率底噪，带动 PPL 突破 32.50；
- 配合已修复的 `if train:` 保护，测试集评估时模型将真正以 0.15 的偏置尺度计算困惑度。
