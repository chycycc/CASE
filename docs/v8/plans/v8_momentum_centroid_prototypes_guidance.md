## 2. 核心病理机制的理论根因定位 (Root-Cause Diagnosis)

通过对 `src/models/CASE/model.py` 计算图与张量尺度的严格物理审查，定位出导致原型漂移扎堆与流形胶着的三大根因：

### 根因 1：原型定义为“脱离样本的悬浮参数”，而非“样本真实几何质心”
- **代码现状**：原型定义为 `self.prototypes = nn.Parameter(torch.empty(total_protos, 300))`，是一个靠梯度极其缓慢挪动的独立参数矩阵；
- **病态机理**：在复杂的非凸损失曲面上，该参数矩阵并未在数学定义上与当前类别的真实样本均值绑定。它漂移在一个全局伪最优位置，在物理上没有强行坐落在测试样本特征云团的几何重心（Centroid）。

### 根因 2：双头梯度物理撕裂（分类头拉扯 A，对比学习拉扯 B）
- **代码现状**：
  - 分类头 `emotion_linear` 作用于双图融合特征：`emotion_enc = emo_gate * concept_enc + (1 - emo_gate) * fine_emotion`；
  - 但 EPCL 原型对比损失拉扯的，却是前级局部特征：`fine_emotion`；
- **病态机理**：分类交叉熵与对比学习的梯度反向传递给不同的张量节点，隐空间优化目标发生物理撕裂，无法往同一个方向凝聚。

### 根因 3：缺乏“硬边际（Margin）”，对比损失在 0.5 相似度平原“躺平”
- **实测数据**：样本与自身正原型的相似度为 0.5069，与负原型的相似度为 0.5436；
- **病态机理**：现有的 InfoNCE 软 Softmax 损失在面对 0.50 vs 0.54 时梯度极其微弱，模型陷入局部平原极小值。由于缺乏类似人脸识别（ArcFace / CosFace）中的**角度硬边际（Additive Angular Margin, $m$）**，损失函数无法提供足够的排斥力强行推开负类别。

## 3. V8 核心架构方案：CASE-MCP (Momentum Centroid Prototypes)

为了彻底解决上述硬伤，V8 确立三大精准重构手术：

```
                              [ 用户对话输入 Context ]
                                         │
                 ┌───────────────────────┴───────────────────────┐
                 ▼                                               ▼
         [ COMET 认知图流 ]                              [ ConceptNet 情感图流 ]
                 │                                               │
           fine_emotion                                     concept_enc
                 └───────────────────────┬───────────────────────┘
                                         ▼
                 [ 门控融合节点: emotion_enc (统一挂载锚点) ]
                                         │
         ┌───────────────────────────────┴───────────────────────────────┐
         ▼                                                               ▼
 [ 情感分类头 emotion_linear ]                                   [ V8 核心: EPCL-MCP 模块 ]
         │                                                               │
  L_CE 交叉熵损失                                            [ 投影头 ERP (768d 解缠) ]
                                                                         │
                                                                   z (归一化特征)
                                                                         │
                                         ┌───────────────────────────────┴───────────────────────────────┐
                                         ▼                                                               ▼
                       [ 动量样本中心原型 (MCP) ]                                   [ 角度硬边际损失 (Arc-EPCL) ]
                                         │                                                               │
                       P_c = μ·P_c + (1-μ)·Mean(z_c)                             cos(θ_y) - m (强制硬间隔排斥)
                     (数学强制原型 100% 处于样本质心)                               (推动 Silhouette 轮廓系数由负转正)
```

---

### 手术 1：动量样本中心原型 (Momentum Centroid Prototypes, MCP)
- **机制设计**：
  1. 彻底废除悬浮的 `nn.Parameter` 独立原型；
  2. 原型矩阵 `prototypes` 注册为 `buffer`（不参与反向梯度更新）；
  3. 每个训练 Batch 中，统计属于类别 $c$ 的所有样本特征集合 $\mathcal{B}_c$；
  4. 计算当前批次样本的均值质心：
     $$\mathbf{v}_c = \frac{1}{|\mathcal{B}_c|} \sum_{i \in \mathcal{B}_c} \mathbf{z}_i$$
  5. 通过指数移动平均（EMA，动量系数 $\mu = 0.99$）平滑滚动更新原型：
     $$\mathbf{P}_c^{(t)} = \text{Normalize}\left(\mu \mathbf{P}_c^{(t-1)} + (1 - \mu) \mathbf{v}_c\right)$$
- **预期收益**：
  **原型在数学定义上严格等于全数据集该类别样本特征的几何重心！**  
  五角星在任何降维投影中，物理上 100% 必须位于各情绪簇的高密度正中央，彻底消灭原型漂移与扎堆。

---

### 手术 2：统一表征挂载锚点
- **机制设计**：
  将 `src/models/CASE/model.py` 中 EPCL 的输入统一修正为 `emotion_enc`（即与分类头完全同源的融合特征）；
  将对比学习权重 $\lambda_{\text{epcl}}$ 由过弱的 `0.07` 适度提升至 `0.15 ~ 0.25`。
- **预期收益**：分类交叉熵与对比损失对同一特征施加梯度，彻底消除特征撕裂。

---

### 手术 3：加性角度硬边际损失 (Additive Angular Margin Loss, Arc-EPCL)
- **机制设计**：
  在投影特征超球面上引入类似 ArcFace 的加性角度硬间隔 $m$：
  $$\mathcal{L}_{\text{margin}} = -\log \frac{\exp\left(\frac{\cos(\theta_{i, y_i}) - m}{\tau}\right)}{\exp\left(\frac{\cos(\theta_{i, y_i}) - m}{\tau}\right) + \sum_{j \neq y_i} \exp\left(\frac{\cos(\theta_{i, j})}{\tau}\right)}$$
  初始推荐参数：边际间隔 $m = 0.25 \sim 0.35$，温度 $\tau = 0.15 \sim 0.20$。
- **预期收益**：
  强制要求正样本与正原型的余弦相似度必须压倒性大于负样本至少 $m$ 的绝对差值，打破 0.50 vs 0.54 的胶着状态，**直接推动 Cosine Silhouette 轮廓系数由负转正（冲刺 > +0.10）**！

## 4. V8 实施路线图与消融规划 (Implementation Roadmap)

1. **Phase 1: MCP 动量中心原型独立上线与可视化验证**
   - 目标：将原型重构为 EMA 样本质心更新机制，修复可视化脚本中的模长失配；

2. **Phase 2: 统一挂载点与角度硬边际 (Arc-EPCL)**
   - 目标：将挂载点接入 `emotion_enc`，开启角度硬边际 $m=0.30$；
   - 验收标准：测试集 Cosine Silhouette 轮廓系数突破 0.00 翻正，DBI 进一步下降至 3.5 以下。
3. **Phase 3: 自适应多样性解码联合验收**
   - 目标：在良构流形基底上运行自适应核采样解码；
   - 验收标准：维持 Dist-2 > 30.0% 与唯一句率 > 94.0%，且测试集分类准确率取得显著实质性突破。
